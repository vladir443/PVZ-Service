# Публикация PVZ Service в Amvera

## 1. Создание приложения

1. Откройте `https://cloud.amvera.ru/projects`.
2. Нажмите `Создать`.
3. Выберите тип `Приложение`.
4. Укажите название `pvz-service`.
5. Выберите тариф `Начальный`.

## 2. Загрузка проекта

На шаге загрузки данных можно использовать один из вариантов:

- загрузить архив проекта через интерфейс;
- добавить выданный Amvera Git-репозиторий как remote и отправить ветку `main` в `master`.

Файл `amvera.yml` уже находится в корне проекта. Он запускает Node.js 22,
открывает порт 3000 и подключает постоянное хранилище `/data`.

## 3. Переменные

В настройках приложения при необходимости добавьте:

- `TELEGRAM_BOT_TOKEN` — напоминания через Telegram;
- `ADMIN_TELEGRAM_IDS` — Telegram ID главного администратора;
- `SMS_WEBHOOK_URL` — адрес сервиса отправки SMS;
- `SMS_WEBHOOK_TOKEN` — токен сервиса отправки SMS.

`DATABASE_PATH` указывать не нужно: в Amvera база автоматически сохраняется
в `/data/grafik.db`.

## 4. Домен

После успешного запуска откройте `Настройки` → `Доменные имена` →
`Добавить доменное имя` и выберите бесплатный HTTPS-домен Amvera.
